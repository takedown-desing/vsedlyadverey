Как загрузить изменения

  1. Откройте скачанный файл в Excel или Google Таблицах, внесите правки. Лишние колонки можно удалить: загружаются только те, что остались.
  2. Сохраните как CSV: в Excel «Файл → Сохранить как → CSV (разделители — точка с запятой)» или «CSV UTF-8».
  3. В админке: Настройки сайта → Импорт из CSV → прикрепите файл → «Сохранить».
  4. Меню аккаунта (кружок вверху справа) → Publish Changes. Через 2–3 минуты изменения будут на сайте, а результат в Настройки сайта → Отчёт об импорте.

Хотите сначала проверить файл? Поставьте галочку «Только проверить, ничего не менять»: отчёт покажет ошибки, сайт не изменится.
