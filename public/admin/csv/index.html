Как загрузить изменения

  1. Откройте скачанный файл в Excel или Google Таблицах, внесите правки. Лишние колонки можно удалить: загружаются только те, что остались.
  2. Сохраните файл как есть: .xlsx («Книга Excel»). Подходит и CSV. Старый формат .xls не принимается: пересохраните его как .xlsx. Из Google Таблиц: «Файл → Скачать → Microsoft Excel (.xlsx)».
  3. В админке: Настройки сайта → Импорт из Excel или CSV → прикрепите файл → «Сохранить».
  4. Меню аккаунта (кружок вверху справа) → Publish Changes. Через 2–3 минуты изменения будут на сайте, а результат здесь, в блоке «Последняя загрузка» (обновите страницу). В админке он тоже есть: Настройки сайта → Отчёт об импорте, но чтобы его увидеть, обновите страницу админки.

Хотите сначала проверить файл? Поставьте галочку «Только проверить, ничего не менять»: отчёт покажет ошибки, сайт не изменится.

Новые товары: достаточно названия

Для нового товара обязательна только колонка «Название» (подойдёт и «Наименование»). Файл из одной колонки с названиями загрузится: каждая строка станет карточкой товара. Всё, что не заполнено, сайт подставит сам:

Не заполненоЧто будет на сайте
ФотоЗаглушка «Фото скоро появится»
Цена«Цена по запросу», товар можно положить в корзину
РазделТовар виден в общем каталоге и в поиске, но не в разделах
Бренд, покрытие, характеристики, описаниеНе показываются; покрытие считается «стандартным»
Наличие«На складе поставщика»

Отчёт после загрузки перечислит, чего не хватает у каждого нового товара. Дозаполнить можно позже тем же способом или в карточке товара в админке.

Названия колонок можно писать по-своему: «Наименование», «Категория», «Производитель», «Стоимость», «Наличие», «Цвет», «Изображение» тоже понимаются.
